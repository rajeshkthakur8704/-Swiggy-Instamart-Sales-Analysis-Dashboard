# 🛒 Swiggy Instamart Sales Analysis Dashboard

## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of Swiggy Instamart sales performance, customer orders, product categories, shop types, city tiers, and ratings.

## 🎯 Business Objective

- Total Sales Performance
- Order Trends
- Product Category Contribution
- Shop Performance by Type
- City Tier Analysis
- Customer Ratings
- Shop Opening Trends

## 📊 Key Performance Indicators (KPIs)

| KPI | Value |
|------|--------|
| Total Sales | 1.20M |
| Total Orders | 8,523 |
| Average Rating | 3.92 |
| Average Sales | 141.01 |

## 📈 Dashboard Features

- Total Sales by City Tier
- Total Orders by City Tier
- Product Category Analysis
- Shop Type Performance
- Average Ratings Analysis
- Interactive Filters

## 🔍 Key Insights

- Tier 3 cities generated the highest sales contribution.
- Fruits & Vegetables category recorded the highest revenue.
- Average customer rating remained stable around 3.9.
- Shop openings declined significantly in 2024.
- Supermarket Type 1 generated the highest sales and order volume.

## 🛠️ Tools & Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
